# Marca — Copa Jumentus 2027

Identidade híbrida: **estrutura MLS** (oito franquias, diagonais a 45°, letras condensadas, módulos de transmissão) com **atmosfera Vice City** (céu de pôr do sol, palmeiras, noite roxa e neon racionado).

| Arquivo | Para quê |
|---|---|
| [`manual-de-marca.md`](manual-de-marca.md) | Regras de logo, cores (institucional, Vice City e times), tipografia, elementos e peças |
| [`skill-gemini/SKILL.md`](skill-gemini/SKILL.md) | Instruções da skill `copa-jumentus-design` no Gemini, que melhora o acabamento das artes base |

A versão completa e comentada do manual, com tom de voz e checklist, fica no documento "Manual de Marca — Copa Jumentus 2027". Os arquivos de logo estão em [`public/imagens/logo/`](../../public/imagens/logo/).

Para montar a skill no Gemini, envie `skill-gemini/SKILL.md`, `manual-de-marca.md`, `copa-jumentus-logo.png` e `copa-jumentus-logo-brilho.png`.

Ao mudar a marca, atualize os dois arquivos daqui junto com o documento.
